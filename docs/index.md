# LLM Evaluation Workbench

Benchmark-Workbench fuer den systematischen Vergleich lokaler LLMs (Ollama, llama.cpp)
mit Siemens-Cloud-LLMs fuer Oracle-zu-PostgreSQL-Migrationen.

**Aktueller Stand:** siehe [AGENTS.md](https://github.com/thomasdenk79-cyber/llm-evaluation-workbench/blob/main/AGENTS.md)

python scripts\llm_migration_benchmark.py --backend siemens --runs 3
