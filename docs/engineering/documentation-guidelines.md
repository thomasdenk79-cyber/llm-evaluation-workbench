# Documentation Guidelines

## Ziel

Technische Dokumentation muss reproduzierbare Benchmark-Laeufe ermoeglichen.

## Pflichtupdates

Bei folgenden Aenderungen Dokumentation aktualisieren:

- CLI-Parameter im Benchmark-Skript
- Bewertungslogik (Score/Gewichtung)
- Ergebnisformat (CSV/JSON-Felder)
- Empfohlene Run-Befehle oder Power-Profil-Ablauf

## Konsistenz

- README enthaelt Quickstart.
- Runbook enthaelt operative Schrittfolge.
- Changelog enthaelt zeitliche Aenderungshistorie.
